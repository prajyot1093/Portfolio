## 🛠️ Tech Stack & Desktop Apps

- **Bear App**: Interactive notes featuring Biography, Technical Skills, Experience, Projects, and GitHub Stats.
- **Terminal App**: Functional Unix terminal with custom commands (`cat bio.txt`, `cat skills.txt`, `cat projects.txt`, `whoami`, `ls`, etc.).
- **Safari App**: Interactive browser with quick bookmarks to live demos and profiles.
- **Launchpad**: Visual launcher for projects and apps.
- **VSCode**: Embedded code explorer.
- **Typora**: Markdown note editor.
- **Control Center, Dock & Top Menu Bar**: macOS Sonoma/Ventura style interactive controls.

## 💻 Local Development

1. Install dependencies:
```bash
npm install
```

2. Start the development server:
```bash
npm run dev
```

3. Build for production (Vercel-ready):
```bash
npm run build
```
