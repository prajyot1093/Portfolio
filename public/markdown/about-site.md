# 💻 About This Site

This is an interactive, simulated macOS desktop portfolio built for **Prajyot Punde**.

---

## 🎨 Tech Stack & Highlights

- **Framework**: React + Vite + TypeScript
- **Styling**: UnoCSS + Tailwind Utilities
- **State Management**: Zustand
- **Windowing & Motion**: React RND & Framer Motion
- **Markdown & Code**: Milkdown, React Markdown & Syntax Highlighting

---

## 🧭 Interactive Apps

- **Bear**: Read interactive notes detailing biography, skills, projects, and work experience.
- **Terminal**: A Unix shell emulator with interactive commands (`ls`, `cat bio.txt`, `cat skills.txt`, `cat contact.txt`, `whoami`, etc.).
- **Safari**: Browse live project demos and developer links.
- **VSCode**: Browse the source code directly in an embedded code editor.
- **Launchpad**: Launch web apps and projects with a single click.
